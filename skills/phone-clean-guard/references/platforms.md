# 系统兼容与分流

先确认手机“关于手机”中的系统、版本和型号，再确认电脑实际连接的设备。品牌、外观、包名前缀，以及“USB 调试”字样都不足以决定操作路线。

| 系统／环境 | 本 Skill 的路线 | 自动操作边界 |
| --- | --- | --- |
| Android 主系统，API 26+；含具备 Android 主环境的 EMUI、Magic UI／MagicOS、MIUI／HyperOS、One UI 等 | Python 辅助工具通过 ADB 只读审计；其余入口按实际界面检查 | 自动停用仅限厂商档案列出的型号、系统版本、显示构建号等条件全部匹配的候选项。不匹配时只报告、走界面路线 |
| HarmonyOS 4.x 及以下 | 先探测 ADB 和 Android 包管理能力，满足以上条件才走 Android 路线 | 不把某台华为／荣耀的包清单用于其它机型或固件 |
| 原生 HarmonyOS 5+，含 NEXT | 使用适配该版本的官方 HDC／DevEco 工具识别设备，随后按系统界面审查 | 本版不提供原生鸿蒙包停用、卸载或恢复脚本。HDC 只作已理解且经官方文档核对的只读识别；未确认能力时改由用户在手机查看 |
| Android API 25 及以下、系统未知、ADB 命令或档案不兼容 | 只读识别与界面指导 | 不为强行兼容而试写设置、试卸载或绕过权限 |
| 工作资料、企业管理、隐私空间、多用户、安卓容器 | 先确认空间归属、管理员约束和用户实际要维护的主空间 | 不跨空间操作，不改变设备管理策略；容器内 ADB 成功不能证明主系统支持 Android 操作 |

“提供处理路线”不代表所有机型均已真机验证。具体已验证设备、脚本能力及测试范围以项目文档为准；没有匹配档案不表示该手机不安全，也不应引导用户升级或降级固件以匹配档案。

初始档案没有历史完整 fingerprint 证据，不能称为对每一个底层构建指纹都已验证。审计读取完整 fingerprint 并绑定后续同机操作；计划明确列出匹配字段和证据限制。对自定义 ROM、版本信息矛盾或档案证据不足的设备，使用界面路线，不因字段碰巧匹配而执行。

## Android 与旧版鸿蒙

- 连接电脑、在手机解锁确认授权；无设备、多个设备、离线或未授权时先解决连接，不猜选目标。用户应能确认手机与当前操作对应。
- Android API、当前用户、完整固件构建信息及默认桌面／输入法等能力以设备实际结果为准。读取失败和未知字段不视为匹配成功。
- 华为官方把 HarmonyOS 4.x 及以下的 ADB 调试设置与 5+ 的开发者选项分开说明。不要仅根据版本营销名称判断兼容性。
- Android 8+ 采用按来源的“安装未知应用”权限。旧 `INSTALL_NON_MARKET_APPS` 值不能用来判定当前防误装效果；不要写这个旧键后宣布成功。
- 关闭某个来源的安装权限不会阻止所有可信商店或 ADB 安装；关闭个性化广告也不会保证广告数量减少。逐个核验实际入口与跳转，记录剩余入口。

## 原生 HarmonyOS

HDC 与 ADB 是不同工具链。即使 HDC 终端中存在某些同名命令，也不得转用 Android 的 `pm`、`appops`、APK 备份或恢复流程。不要将 Android 容器中的包当作手机原生应用处理。

需要开发者连接时，按当前官方文档与手机提示完成；不要擅自重启来开启开发者模式，不要为精简申请企业管理、root 或调试证书，也不要下载来历不明的工具包。HDC 存在不等于拥有修改系统应用的权限。

优先由系统设置搜索定位“推荐”“广告”“通知”“安装”“桌面”等入口，再进入应用自己的设置确认功能语义。应用市场、元服务、搜索、负一屏、主题等页面随系统与应用版本变化。原生鸿蒙的应用市场与旧版不同，旧“快应用管理”入口已下线，不能用“找不到”推断为关闭成功。

## 厂商界面提示

以下是定位方向，不是可直接盲点的固定菜单或坐标。先查看当前页面、开关和说明，操作后重新进入核验。

- **华为／旧版荣耀**：检查热门或精品推荐云文件夹、小艺建议、负一屏、搜索、锁屏、主题和应用市场的实际入口。推荐图标不一定是已安装应用；移除文件夹入口不等于卸载用户已有应用。保留主题、文件管理、账号等共享能力，优先选择关闭入口或存在的基本服务模式。
- **新荣耀**：搜索内的首页模块与智能推荐、桌面搜索框、桌面下滑动作分别检查。旧版华为包名不作为 MagicOS 操作依据。
- **小米／Redmi／POCO**：MIUI、HyperOS 及应用版本会改变广告设置位置。分别检查桌面文件夹、负一屏、浏览器、主题、视频、文件管理及推广通知；关闭“个性化广告”仍可能看到同等数量广告。
- **三星**：检查通知、商店推荐及来源安装权限。Auto Blocker 是额外安全与安装限制，可能影响侧载和调试，需要说明后按用户选择处理，不作为默认广告开关。
- **OPPO／realme／一加、vivo／iQOO 与其它 Android**：本版没有可跨版本自动套用的设置键或包清单。由当前界面和相应厂商官方说明定位，再逐项记录、核验。

不要通过实际点击广告、下载 APK、同意新服务协议或完成安装来验证防误装。使用安全的界面观察、开关回读与受支持的只读查询；确需用户试用时说明步骤并避免触发交易、电话、短信或资料修改。
