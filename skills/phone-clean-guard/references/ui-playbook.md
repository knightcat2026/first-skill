# 按实际界面关闭推荐与误装入口

先读 [platforms.md](platforms.md) 选择系统路线。以下名称是搜索线索，不能当作所有品牌、版本通用的菜单路径。没有可用的手机界面工具时，请用户在手机上操作并回报实际开关状态；不要推测已完成。

## 操作边界

先列出将关闭的入口、影响的功能和恢复办法，沿用用户已给出的授权。计划获准后连续处理，不必逐项重复询问；新出现的全局禁装、切换默认输入法等超出范围的改变另行确认。默认保留正常安装，不设置全局禁装，不接管设备管理，不接受新的隐私协议、订阅或付款。

不清除应用数据、不恢复出厂、不登出账号、不删除照片、聊天、下载、存储的 APK 或云端内容，不卸载任何已有应用。电话、短信、紧急呼叫、桌面、当前输入法、联系人、文件、相册、支付、账号、安装器、权限管理、系统安全与更新组件均保留。不要因“第三方”或包名前缀判断某应用多余；只关闭其推荐设置，不停用整套用户应用、浏览器、应用市场或快应用引擎。独立推广组件的停用也须说明影响并可恢复。

系统、安全补丁及应用更新功能、更新提醒和自动更新偏好保持原状。不要通过停用商店、冻结更新服务、断网或过滤更新域名来关闭广告。页面中的“自动下载”必须区分推荐软件自动下载与正常更新；语义不明确时保留，记录未处理。

## 分层检查

| 位置 | 查找与处理 | 需要保留或说明 |
|---|---|---|
| 桌面、负一屏、搜索、文件夹 | 关闭资讯卡片、热门应用、云文件夹推荐、自动添加图标、推荐手势提示；按实际界面移除推荐入口 | 文件夹里的推荐图标未必是已安装应用；移除入口不能连同文件夹内真实应用、快捷方式或资料一起删除 |
| 锁屏、壁纸、主题 | 查找杂志锁屏、轮播资讯、推荐内容；若有基本服务或本地模式，说明功能变化后选择 | 保留解锁、壁纸、铃声功能；不要停用整个主题框架；不要为了操作同意在线服务或新增桌面入口 |
| 浏览器、应用市场、快应用 | 分别关闭首页资讯、推广通知、应用推荐、推荐软件自动下载或快捷安装；检查默认首页、启动页和推荐快捷入口 | 不同鸿蒙版本入口不同；保留安全检查、正常安装及更新，不能关闭正常更新的自动下载或安装设置。不停用整个快应用引擎，只改可区分的推荐、拉起和误装入口 |
| 输入法及保留应用 | 在应用自己的隐私、内容、广告设置中分别查找推荐开关 | 关闭个性化不等于广告消失，也未必减少数量；不能停用正在使用或唯一可用的输入法 |
| 通知与悬浮窗 | 关闭已确认推广来源的非必要通知类别；审查可疑应用的悬浮窗权限 | 不批量关闭电话、短信、安全、支付及用户需要的提醒；分清推广通知和功能通知 |
| 跳转与外部安装 | 在“默认打开／打开支持的链接”等界面审查可疑来源；在“安装未知应用／外部来源”中逐个来源查看权限 | 关闭链接关联可能改变正常链接打开方式；关闭某来源安装权限会影响用户从该来源主动安装，需纳入计划说明，不能由一个旧系统设置值推断全部权限 |

从当前屏幕的文字、控件状态和页面结构定位操作，每次修改后重新读取状态。界面变化、不可见控件或权限拒绝时停止该项并记录，不反复盲点，不使用别的机型坐标，也不绕过系统保护。脚本仅对匹配档案的组件执行受限操作；其余入口走正常界面，不能拿历史删包清单补齐。

## 留痕与验收

每项记录：系统及应用版本、实际入口、修改前后状态、功能影响、证据位置、恢复路径。截图和界面记录保存在本地私有维护目录；可能含账号、通知和网络名称，不上传到 GitHub。界面无开关、权限不足、无法验证均如实记录。

回到桌面检查左右滑动、下滑搜索、锁屏、浏览器首页、通知栏、市场与快应用相关入口。仅查询处理程序或使用正常页面检查跳转；不要点击真实广告、接受安装、下载未知安装包、真实拨号、发消息或付款来证明效果。检查电话、短信、联系人、相册、文件和输入法仍可打开；让用户确认原有资料及常用功能，未核实的项目不能标作通过。

核对原有已安装应用未减少；缺失项单独报告，不自行重装或删除其它应用。打开正常系统更新页面，确认入口及功能仍可用，核对更新偏好保持原状；不要触发下载安装或重启。用户资料由机主确认，不为验收读取照片、聊天和文档内容。

结果使用“已关闭／仍有入口／此版本无此功能／未验证”。外部网页广告、应用内通用广告和系统更新后恢复的入口不能普遍消除；报告具体剩余项与复查办法，不宣称所有广告或所有安装渠道已永久杜绝。完成后提示用户按需要关闭 USB 调试或撤销此电脑的调试授权。

系统或应用更新后，可以再次运行检查。新建维护会话并重新识别版本，仅关闭重新开启的入口；已关闭项记录现状即可，不套用旧版本路径、旧停用计划或旧恢复命令。新版本不满足脚本档案时走当前界面。
