# 手机防误装净化

把手机整理成少推荐、少推广、少误触的日常设备，保留用户资料与需要的功能。先识别实际系统，再选正常设置界面或受限的 ADB 辅助工具。不要承诺所有应用、网页广告和未来版本上的“零广告”或“绝不误装”。

范围固定为关闭功能和入口：不删除任何用户资料、已安装应用或手机中保存的 APK 文件；保留系统、安全补丁和应用更新能力及原有更新偏好。不以停用应用市场、浏览器、快应用整套引擎或阻断更新网络来达到净化目的。仅可在影响已说明且获授权时停用独立推荐组件，不能把本 Skill 扩展成卸载或清理存储的工作流。

## 确定范围与系统

- 延续用户已经作出的选择。默认保留正常安装；“关闭推荐”不授权全局禁装、企业管理、家长控制、换输入法或卸载用户应用。用户主动要求更强限制时解释影响并明确范围，不重复索取已经给出的授权。
- 读取 [platforms.md](references/platforms.md) 的分流表。以手机设置中的主系统版本和实际调试能力为准，不能只看品牌、Android 兼容层或用户口述型号。
- 原生 HarmonyOS 5+ 使用其正常界面和官方 HDC 识别路线；本 Skill 的 Python 工具仅支持主系统为 Android 的 ADB 环境。不向原生鸿蒙或 Android 容器发送 `pm`、`appops`、APK 命令。
- 无授权连接、多设备、工作资料/企业管理、系统识别不清：先只读审查，处理相应问题，不跨空间操作。调试授权由机主在手机上确认。
- 使用顺序为：USB 连接、开启开发者选项及相应调试、机主在手机确认授权、由支持 Skill 的 AI 工具加载执行。下载 Skill 或只开启开发者选项，不代表已建立可操作连接。

## 保留资料的执行方式

优先关闭功能入口，其次停用已确认独立的推荐组件。本 Skill 不执行卸载、清空数据、删除目录、恢复出厂、解锁、刷机或 root。`uninstall -k` 也不是资料备份，不能据此保证资料安全。

按 [ui-playbook.md](references/ui-playbook.md) 在当前界面逐层检查：桌面/锁屏、浏览器/市场/快应用、通知/悬浮窗/链接、输入法和主题的推广入口。显示“个性化关闭”不能算广告已关闭。保留紧急呼叫、电话短信、联系人、照片文件、当前桌面/输入法、账号、无障碍需求、权限管理、系统更新和安全检查。

给出具体计划：对象、用途依据、操作、功能影响、恢复入口。执行用户已授权的计划；新增全局安装限制等范围变化才另行确认。未授权时完成只读报告，不把待确认项当已完成。

执行前为每项记录最小必要的原状态与恢复方式，放在用户指定的私密位置。它是设置/停用记录，不是照片、聊天、应用私有数据的完整备份。用户需要完整备份时采用厂商支持的备份工具，不能把 APK 导出说成聊天记录备份。

## 可选 ADB 工具

需要自动化识别、可复核的停用与恢复时，读取 [adb-helper.md](references/adb-helper.md)，使用 `scripts/phone_guard.py`（Python 3.10+ 标准库，官方 Platform Tools）。

- `audit` 只读采集最小清单；`plan` 仅在电脑生成计划；`apply` 才会停用，且只允许附带档案列出的型号、系统版本、构建号等条件全部匹配的候选项。计划会列出匹配字段和验证程度，须一并审查。
- 初始历史档案未记录完整固件指纹；工具读取的完整指纹用于首次审计后的设备/固件绑定，不证明其它指纹的固件已验证。不能把字段匹配或模拟测试说成新设备的真机安全保证。
- 其它 Android 设备仍可做只读检查并按界面处理。没有匹配档案时不生成自动停用清单、不套用旧包名。不要为绕过拒绝而临时放宽档案；新档案走 [contributing-profiles.md](references/contributing-profiles.md) 的验证流程。
- 工具在修改前写入恢复日志，绑定同一手机和固件，并回读状态；失败就停止，不能用提权或批量重试掩盖系统拒绝。`restore` 恢复原始默认/启用状态。
- 不运行网上的整套“去广告一键删包”命令。附带档案不代表其它同品牌手机也安全，更不等于完整广告清单。

## 验收与交付

回读开关并检查入口实际行为；复查默认桌面、输入法与电话/短信/文件等核心页面能否正常打开。不要真实拨号、发送消息、付费、点广告或安装陌生应用来验证。重启属于另一步，告知用户自行重启后复查；未重启不得声称验证了重启持久性。

核对维护前的已安装应用仍存在；无法解释的缺失单独报出，不猜测原因、不自行重装。打开正常系统更新页面，确认入口及功能仍可用，并核对更新偏好未改变；不触发下载、安装更新或重启。不要为检查资料保留而读取照片或聊天内容。

按“已关闭 / 仍有入口 / 此版本无此功能 / 未验证”逐项交付，说明保留的功能影响、恢复方法与剩余限制。通知关闭、推荐停用、个性化关闭、来源安装权限、全局禁装分别报告。没有报错不等于完成。

结束时提醒断开 USB 后关闭不再需要的调试，并可撤销本次电脑的调试授权；不撤销其它已知设备的权限。系统升级或应用更新可能恢复入口，提供复查方法，不暗中创建后台常驻任务。

更新后再次使用时，新建私密审计会话、重新识别主系统与版本，只处理重新开启的入口。不能重放旧计划、沿用旧固件匹配结论或把已关闭项反复操作；新版本没有匹配档案时走正常界面。保留旧日志用于参考，不让旧恢复指令覆盖更新后的配置。

本地报告、应用清单、UI 截图/XML 和调试标识都作为私密资料，不进 GitHub。官方依据见 [sources.md](references/sources.md)。
